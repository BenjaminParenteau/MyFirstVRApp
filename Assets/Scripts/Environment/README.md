Shared visual style kit (materials, lighting profile, modular prefab set) that every system builds inside of, so scenes built by different engineers stay visually consistent. Standards live in docs/StyleGuide.md. `Editor/StyleKitBuilder.cs` generates the kit into Assets/Content/StyleKit/ (menu: High Stakes > Build Style Kit) and can check a scene against it (High Stakes > Validate Open Scene Against Style Kit). `SharedStyleKit.cs` is the ScriptableObject that references everything. Owned by Slot D.
