Shared visual style kit (materials, lighting profile, modular prefab set) that every system builds inside of, so scenes built by different engineers stay visually consistent. Standards live in docs/StyleGuide.md. `Editor/StyleKitBuilder.cs` generates the kit into Assets/Content/StyleKit/ (menu: High Stakes > Build Style Kit) and can check a scene against it (High Stakes > Validate Open Scene Against Style Kit). `SharedStyleKit.cs` is the ScriptableObject that references everything. `Editor/RenderingOptimizer.cs` (High Stakes > Rendering) adds culling LODs to small static details and bakes occlusion culling per area scene; `WorldBuilder` runs it after rebuilding. Owned by Slot D.

Back of house: `Editor/HallwayBuilder.cs` generates the hub and wings (security & count room and camera room 12 x 12 m, vault 8 x 8 m); `Editor/CountRoomBuilder.cs` builds the count floor and supervisor booth (`NPC_Supervisor` anchor for the NPC later); `Editor/BackOfHouseBuilder.cs` (**High Stakes > Build Security & Camera Rooms (12 x 12)**) regenerates those two rooms and furnishes everything, and Build MVP World furnishes too.
