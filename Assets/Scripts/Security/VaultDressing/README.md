# Treasury dressing and open vault doorway

The treasury room physically adjoins the hallway. One outward-open vault door remains visible from either side, and the player walks through the actual opening without a picture surface or internal teleport.

There is no custodian key, key pickup, keyhole interaction, wheel-unlock requirement, or additional inventory behavior from this dressing module.

Rebuild the art with **High Stakes > Vault > Build Treasury Dressing**. After regenerating the hallway scene, run **Connect Actual Vault Room** to align the room and clear visibility data baked for its previous location.
