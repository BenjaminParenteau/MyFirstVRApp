Slot D (Zach): textured casino floors and walls. Built by High Stakes > Casino Textures > Build Casino Textures
(Assets/Scripts/Environment/Editor/CasinoTextureBuilder.cs); import settings come from CasinoTextureImporter.cs.

- Materials/  Material Variants of the shared kit materials (only textures, tiling, colour and smoothness overridden):
  M_CasinoCarpet (of M_CarpetRed), M_MarbleFloor (of M_PlasterCream), M_Wallpaper (of M_PlasterCream, relief only),
  M_WoodPanel (of M_WoodDark), M_PictureFrame (of M_BrassGold), M_PictureCanvas (of M_PlasterCream).
- Prefabs/    Prefab Variants of the kit pieces, same size and colliders: Env_CasinoFloor_Carpet, Env_CasinoFloor_Marble
  (of Kit_FloorTile_Warm), Env_CasinoWallPanel (of Kit_CasinoWallPanel); Env_PictureFrame (FBX, visual only).
- Textures/   2K sources. On Android they import as ASTC 6x6, max 1024, mipmaps on.
- Models/     fancy_picture_frame_01.fbx (938 triangles).

To use them in a scene you own: run High Stakes > Casino Textures > Apply Casino Textures To Open Scene. It also textures
large plain floor/wall cubes that use the kit carpet, cream or dark wood (how MVP_Casino is built), with per-size
variants in Materials/Tiled/. Pattern sizes are the *Repeat constants at the top of CasinoTextureBuilder.cs.

T_CasinoCarpet_Albedo.png is our own, generated by tools/generate_casino_carpet.py in the kit palette (1 m tile).
