Slot D (Zach): textured back-of-house rooms (security office, camera room, vault). Built and applied by
High Stakes > Security Textures > Build And Apply To Security Wings (Assets/Scripts/Environment/Editor/SecurityTextureBuilder.cs);
import settings come from CasinoTextureImporter.cs. HallwayBuilder runs it after rebuilding the wings.

- Materials/  Material Variants of the shared kit materials (only textures, tiling, colour and smoothness overridden):
  M_SecurityWall (of M_ConcreteCool), M_SecurityFloor (of M_TileCool), M_VaultFloor and M_SecuritySteel (of M_SteelCool),
  M_SecurityCeiling (of M_PlasterCream). Tiled/ holds per-size variants (e.g. the vault door).
- Prefabs/    Prefab Variants of the kit pieces for new rooms, same size and colliders: Env_SecurityFloor_Concrete,
  Env_SecurityFloor_Plate (of Kit_FloorTile_Cool), Env_SecurityWall (of Kit_Wall_Cool), Env_SecurityCeiling (of Kit_CeilingTile).
- Textures/   1024 px, made by tools/generate_security_textures.py. On Android they import as ASTC 6x6, mipmaps on.

Applying to a scene only overrides the material on the existing kit pieces, so baked lightmaps stay valid. It also gives
Env_PortalDoor_Cool a steel leaf and a cinder-block frame. Warm casino hallways are not touched. Pattern sizes are the
*Repeat constants at the top of SecurityTextureBuilder.cs.

The photo albedos are recoloured into the kit palette by the script (grey, average = ConcreteCool / TileCool / SteelCool),
so the materials use a white base colour. Normal maps are unchanged (OpenGL convention).
T_SecurityCeiling_* (acoustic drop-ceiling grid, 0.5 m tiles) is our own, generated by the same script.
